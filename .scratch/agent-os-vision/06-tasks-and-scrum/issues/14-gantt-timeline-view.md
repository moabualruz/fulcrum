# Gantt / Timeline view — svelte-gantt, dependency arrows, drag reschedule

## Parent
PRD: `.scratch/agent-os-vision/prds/06-tasks-and-scrum.md` (issues breakdown lines T6-24)

## What to build
SvelteKit Gantt/Timeline view (`?view=timeline`) using `svelte-gantt`. Horizontal
timeline with tasks as bars by `start_date` → `due_date`. Dependency arrows rendered
between blocked tasks. Drag-reschedule updates `start_date`/`due_date`. 6-month
timeline with no scroll jank. CLI `fulcrum tasks list --format gantt --json`. TUI
ASCII Gantt (week bars).

## Acceptance criteria
- [ ] Web: `svelte-gantt` instance renders task bars positioned by `start_date`/`due_date`; tasks without start_date use `created_at` as start
- [ ] Web: dependency arrows — for each `blocks` relationship, draw connector arrow from blocking task end to blocked task start
- [ ] Web: drag task bar left/right → `tasks.update({start_date, due_date})` optimistic; resize right edge → update `due_date`
- [ ] Web: 6-month scroll range renders without jank (RAF animation measured < 16ms per frame in Playwright performance trace)
- [ ] Web: zoom controls (day/week/month/quarter view); active zoom persisted in `localStorage`
- [ ] Web: task bar click opens task detail modal
- [ ] Web: `Task` entity gains `startDate` date property; MikroORM migration class auto-generated by `mikro-orm migration:create` adds column to `tasks` table
- [ ] CLI: `fulcrum tasks list --format gantt --project <id> --json` returns `{id, title, start_date, due_date, blocks[], blocked_by[]}[]`
- [ ] TUI: `G` key opens ASCII Gantt panel — one row per task, week bar using `█` characters; task name left-column 30 chars; current day marker
- [ ] Tests: dependency arrows render for a fixture with 2 linked tasks (DOM query finds SVG path elements)
- [ ] Tests: drag reschedule updates both dates correctly
- [ ] Tests: 6-month performance — 100 tasks render < 500ms (performance.now in test)
- [ ] Tests: `start_date` migration idempotent

## Notes / Tech-stack hints
- Failure gate: `svelte-gantt` < 618 stars, no keyboard a11y, or >6mo scroll perf issue → replace with `vis-timeline` (Apache/MIT) imperative wrapper (~1 day); wrap in `<GanttChart>` component so the swap is invisible to parent routes
- `SVAR Svelte Gantt` (MIT) is 3rd fallback if both primary choices fail
- Dependency arrow rendering requires SVG overlay layer; `svelte-gantt` exposes slot for overlays
