## Parent

Pillar 13 — API Surface + Webhooks + Connector Framework

## What to build

Mount Hono + `@hono/zod-openapi` at `/api/v1` gated by `FULCRUM_FEATURES=public-api`. When flag is OFF, all `/api/v1/*` routes return 404. When ON: JWT bearer auth middleware (`Better-Auth.verifyToken`), sliding-window rate limiter using `rate_limit_buckets` table (100 req/60s default per org, configurable via `tenant_settings`), and OpenAPI 3.1 spec auto-generated from zod-openapi registrations served at `/api/v1/openapi.json`. Rate limiter returns 429 + `Retry-After` header at limit. Failure gate: if `@hono/zod-openapi` breaks, hand-generate spec from Zod schemas via `zod-to-json-schema`.

- **Web**: `/settings/api` page calls `auth.tokens.*` tRPC; rate limit usage bar reads `rate_limit_buckets`.
- **CLI**: `fulcrum api tokens list|create|revoke --json` via tRPC in-process.
- **TUI**: Settings → API Tokens screen: list (`Enter`), create (`n`), revoke (`D`).

## Acceptance criteria

- [ ] Migration class `Migration<timestamp>` covering `RateLimitBucket` entity (`src/db/entities/api/RateLimitBucket.ts`): properties `orgId`, `tokenHash`, `windowStart`, `requestCount`; `@Unique({ properties: ['orgId', 'tokenHash', 'windowStart'] })`; composite `@Index({ properties: ['orgId', 'tokenHash', 'windowStart'] })`; auto-generated by `mikro-orm migration:create`.
- [ ] `FULCRUM_FEATURES=public-api` OFF → `GET /api/v1/openapi.json` returns 404.
- [ ] `FULCRUM_FEATURES=public-api` ON → `GET /api/v1/openapi.json` returns valid OpenAPI 3.1 JSON (validated against `oas-validator` in CI).
- [ ] JWT missing/expired → 401 `{ error: { code: 'UNAUTHORIZED', message: '...', requestId: '...' } }`.
- [ ] 101st request in 60s window → 429 + `Retry-After` header; 102nd same; 61st second resets; per-org bucket isolation.
- [ ] API token CRUD: `auth.tokens.create` stores SHA-256 hash; `auth.tokens.revoke` invalidates JWT verify on next call; `auth.tokens.list` returns masked tokens.
- [ ] Web `/settings/api`, CLI `fulcrum api tokens list --json`, TUI Settings → API Tokens all reach same token list from same DB state.
