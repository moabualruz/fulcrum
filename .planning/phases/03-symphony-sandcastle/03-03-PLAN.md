</objective>

<threat_model>
Threats:
- T-03-07: concurrent orchestrators double-dispatch the same task.
- T-03-08: stale running sessions continue after tracker state changes.
- T-03-09: stall detection ignores active Codex events or kills healthy sessions.
Mitigations:
- Preserve DB compare-and-swap claim semantics and partial unique index.
- Reconcile running issues before every dispatch tick.
- Use `last_codex_timestamp` first for stall cutoff, falling back to `started_at`.
Block on: high.
</threat_model>
