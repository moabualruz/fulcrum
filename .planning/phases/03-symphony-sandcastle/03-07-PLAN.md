# Plan 03-07: SYM-12 + SYM-13 Gap Closure

## Objective

1. **SYM-12** — Call `assertWorkspacePathInOrgRoot` inside `createWorkspace` before mkdir (pre-launch path-inside-root guard)

- Conformance tests assert both behaviors
- All 80+ existing conformance tests still pass

<action>

```typescript
const workspacePath = await deps.createWorkspace(run);
```
