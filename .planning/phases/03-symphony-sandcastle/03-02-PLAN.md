<objective>
Make Fulcrum native tracker the strict Symphony authority: full 12-field Issue model, full blocker refs, deterministic candidate ordering, per-state concurrency inputs, ingest-only external tracker boundary, and run state refresh/reconciliation primitives.
</objective>

<threat_model>
Threats:
- T-03-04: partial issue rows render incomplete prompts or dispatch wrong task.
- T-03-05: unresolved blockers are silently treated as dispatchable.
- T-03-06: external tracker adapter becomes a second mutable authority.
Mitigations:
- Zod schema requires every Issue field and full blocker refs.
- Missing blocker refs throw typed tracker errors.
- External trackers remain ingest-only; dispatch APIs accept native Fulcrum tracker data only.
Block on: high.
</threat_model>

<must_haves>
<truths>
- D-01: native tracker adapter is strict about all 12 Issue fields.
- D-02: `blocked_by` returns full `{id, identifier, state}` refs.
- D-03: `agent_runs.orchestration_state` is single mutable orchestration authority.
- D-04: external trackers are ingest-only in Phase 3.
- D-05: future external dispatch parity is deferred.
</truths>
</must_haves>
