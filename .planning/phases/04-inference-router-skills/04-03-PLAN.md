<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| external backend -> probe service | remote/local provider can fail or lie |
| CLI/tRPC/doctor -> operator | health state drives operator trust |
| local process -> sidecar socket | stale PID/socket can spoof running state |
