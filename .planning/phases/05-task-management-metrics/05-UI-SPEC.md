### Accessibility

**Focus Management:**
- Tab order per screen documented in each screen section
- All dialogs trap focus and return to invoking element on close
- Side panel traps focus; `Escape` returns to triggering element
- Command palette traps focus; `Escape` returns to previous focus
- Bulk action toolbar: first action button gets focus on toolbar appear

**ARIA Labels:**
- Chart canvases: `role="img"` + `aria-label="Burndown chart for Sprint {name}: {X} of {Y} points remaining"`
- Kanban columns: `role="region"` + `aria-label="{status} column, {N} tasks"`
- Board cards: `role="article"` + `aria-label="Task: {title}, {status}, {priority}"`
- Bulk checkboxes: `aria-label="Select task: {title}"`
- Filter chips: `aria-label="Filter: {field} {operator} {value}. Press delete to remove."`
- Reactions: `aria-label="{emoji name}: {count} reactions. Press to toggle."`
- Resolved comments: `aria-label="Resolved comment by {author}: {first 50 chars}"`
- Watcher avatars: `aria-label="{N} watchers: {name1}, {name2}, and {N-2} others"`
- Progress bars: `role="progressbar"` + `aria-valuenow={current}` + `aria-valuemin={0}` + `aria-valuemax={max}` + `aria-label="Sprint capacity: {X}%"`
- Gantt bars: `role="img"` + `aria-label="Task {title}: {start_date} to {due_date}"`
- Calendar cells: `role="gridcell"` + `aria-label="{date}: {N} tasks"`

**Keyboard Alternatives:**
- Drag-and-drop (kanban): context menu with "Move to column" submenu listing all statuses
- Drag-and-drop (Gantt): date picker in task detail panel
- Drag-and-drop (calendar): date picker in task detail panel
- Drag-and-drop (backlog→sprint): "Move to sprint" in task context menu
- Chart interaction: data table view toggle for every chart (accessible alternative to hover tooltips)

**Screen Reader Behavior:**
- Chart data available as visually hidden data table below each chart
- Status changes announced via `aria-live="polite"` region
- Bulk operation results announced via `aria-live="assertive"`
- Real-time presence changes announced via `aria-live="polite"`
- Comment add/resolve announced via `aria-live="polite"`

## TUI ASCII Charts (D-83, D-87)

All chart types render in terminal using box-drawing characters and Unicode blocks via `asciichart`.

| Chart | Rendering |
|-------|-----------|
| Burndown | `▓` (dark shade) for actual, `░` (light shade) for ideal, axis with day labels |
| Burnup | `▓` for completed, `░` for scope, dual lines |
| Velocity | `█` (full block) bar per sprint, numeric label above each bar |
| CFD | Stacked `▓░▒` per status with legend below |
| Cycle time | `·` sparkline with median marker `┼` |
| Throughput | `▪` bar per week |
| WIP | `▓` area fill |
| Monte Carlo | `▓▒░` layered bands for probability |

TUI canvas: 12 terminal rows for all chart types. Chart title above (bold). Legend below as `[■ Label]` per series. No color-only encoding — all series labeled.
