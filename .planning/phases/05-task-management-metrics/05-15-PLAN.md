**WorkflowEditor.svelte** (D-23, D-24):
- Fetch current transition graph via `trpc.workflows.getTransitions.query({ projectId })`
- Render as visual node-edge diagram:
  - Status nodes (circles/boxes) positioned in 5-category columns (backlog→unstarted→started→completed→canceled)
  - Allowed transitions as directed arrows between nodes
  - Disallowed transitions: no arrow (implicit deny)
- Edit mode: click status → show checkboxes for all possible targets. Check/uncheck toggles transition allowance.
- Save: calls `trpc.workflows.updateTransitions.mutate({ projectId, transitions })`
- Default workflow button: resets to `trpc.workflows.getDefault.query()` defaults
- Show custom status list per project (D-23): status names + category assignment

**AutomationRuleList.svelte** (D-89, D-92):
- Fetch via `trpc.automations.list.query({ projectId })`
- Render list of rules: name, trigger description, action description, enabled toggle, execution count
- Enable/disable toggle: calls `trpc.automations.update.mutate({ id, enabled })`
- Delete button (with confirmation)
- "Add Rule" button opens form:
  - Trigger picker: status_change, assignee_change, label_added, priority_change, due_date_passed, task_created, comment_added
  - Condition builder (optional): field + operator + value
  - Action picker: set_status, set_assignee, add_label, remove_label, set_priority, move_to_sprint, add_comment, subscribe_watcher
  - Action config: value pickers for chosen action type
- "Use Template" button: shows 4 templates from `trpc.automations.templates.query()`, one-click create from template (D-92)

**Route pages:**
- `settings/workflow/+page.svelte`: mounts WorkflowEditor with projectId from params
- `settings/automations/+page.svelte`: mounts AutomationRuleList with projectId from params
- `settings/import/+page.svelte` (D-121): Import wizard UI — select source (Jira/GitHub/Trello/CSV), authenticate, select project mapping, field mapping preview, dry-run results, confirm + import. Progress bar during import. Uses `trpc.import.*` procedures (or direct service calls).

**RecurrenceConfig.svelte** (D-116 — rendered in task detail panel per Plan 07 section 11):
- Popover triggered by repeat icon in task detail
- Three modes: "On schedule" (cron picker — day-of-week + time selectors), "After completion" (interval input in days), "On close" (interval)
- Shows: next scheduled date, occurrences created count, bounds (end date / max occurrences)
- Actions: create rule (calls `trpc.recurrence.create`), delete rule, update template from current task state
- Badge: when rule active, shows "Recurring" indicator on task
