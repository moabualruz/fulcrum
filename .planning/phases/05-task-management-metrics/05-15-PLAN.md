**SprintCloseDialog.svelte** (per D-28):
- Props: `{ sprintId: string; open: boolean; onClose: () => void }`
- Multi-step dialog using shadcn Dialog + RadioGroup:
  1. Step 1: Show incomplete items count. Radio options per incomplete task: "Move to next sprint (rollover)" | "Move to backlog" | "Keep in closed sprint"
  2. Step 2: Confirm action summary
  3. On confirm: call `trpc.sprints.close({ sprintId })` then `trpc.sprints.rollover(...)` for items marked rollover
- Show frozen summary after close: completed, carried over, added mid-sprint, removed, scope change %
- `data-sprint-close` attribute.

**RetrospectiveEditor.svelte** (per D-29):
- Props: `{ sprintId: string }`
- TipTap editor for retrospective notes (same extensions as task description).
- Auto-save on blur or every 5 seconds: `trpc.sprints.saveRetrospective({ sprintId, notes: editor.getJSON() })`.
- Below editor: structured sprint summary (read-only card showing closedSummary data).
- `data-retrospective-editor` attribute.

**SprintSummaryCard.svelte** (per D-38):
- Props: `{ summary: { carried: number; added: number; removed: number; scope_change_pct: number }; completedCount: number; totalCount: number }`
- Card layout with metrics: Completed ({completedCount}), Carried Over ({carried}), Added ({added}), Removed ({removed}), Scope Change ({scope_change_pct}%).
- Color-coded: positive scope change (red text), negative (green text — scope shrunk).

**WorkflowEditor.svelte** (per D-22, D-23, D-24):
- Props: `{ projectId: string }`
- Fetch current transition graph via `trpc.workflows.getTransitions({ projectId })`.
- Visual directed graph: nodes are statuses (colored by category), edges are allowed transitions.
- Render as SVG: status nodes in a grid/flow layout, arrows between allowed transitions.
- Add/remove transitions: click source status → click target status to add edge. Click existing edge to remove.
- Status categories shown by color: backlog=gray, unstarted=blue, started=yellow, completed=green, canceled=red.
- Save: `trpc.workflows.updateTransitions({ projectId, transitions })`.
- `data-workflow-editor` attribute.

**AutomationBuilder.svelte** (per D-89..D-92):
- Props: `{ projectId: string }`
- List existing automations with enable/disable toggle (Switch component).
- "Create Automation" button opens builder form:
  1. Trigger picker: Select from trigger types (status_change, assignment_change, label_added, priority_change, due_date_passed, task_created, comment_added)
  2. Condition (optional): field + operator + value
  3. Action picker: Select from action types (set_status, set_assignee, add_label, remove_label, set_priority, move_to_sprint, add_comment, subscribe_watcher)
  4. Action config: type-specific picker for the value
- Templates section: show 4 predefined templates (D-92) as clickable cards that pre-fill the form.
- `data-automation-builder` attribute.
