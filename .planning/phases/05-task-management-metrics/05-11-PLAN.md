**TaskService.ts D-76 bulk event emission** — In `src/services/TaskService.ts` `bulkUpdate` method:
- After applying the bulk update, emit ONE Event per changed field (not per-task). The Event record uses:
  - `verb: "task.bulk_update"`
  - `fieldName: <the changed field>` (e.g., "status", "assignee", "priority")
  - `fromValue: null` (bulk = heterogeneous from-values)
  - `toValue: JSON.stringify(newValue)`
  - `payload: { affected_task_ids: taskIds }` — array of all affected task IDs in metadata
- This avoids event flood (D-76) while maintaining audit trail.
- Example: bulk-setting 50 tasks to "In Progress" → ONE event with `{ verb: "task.bulk_update", fieldName: "status", toValue: "In Progress", payload: { affected_task_ids: [...50 ids] } }`.
