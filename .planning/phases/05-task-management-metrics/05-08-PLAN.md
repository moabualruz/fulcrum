**TaskBoard.svelte** (D-10, D-11, D-12, D-13):
- Props: `projectId: string`, `sprintId?: string`, `groupBy: 'status'|'assignee'|'priority'|'label'|'sprint'`, `methodology: 'scrum'|'kanban'|'none'`
- Fetch methodology via `trpc.workflows.getMethodology.query({ projectId })` on mount
- Fetch tasks via `trpc.tasks.list.query({ projectId, sprintId })`
- **Methodology-aware rendering:**
  - `scrum`: show sprint selector, backlog tray visible, velocity widget in header, sprint scope filter active
  - `kanban`: show WIP limits prominently, show cumulative flow mini-chart in header, no sprint selector (sprints hidden), continuous flow emphasis
  - `none`: simple column board with no WIP limits, no sprint features, no analytics widgets — just drag between statuses. Generic task list mode.
- Group tasks by selected field into columns/swimlanes
- Each column uses `use:dndzone` from svelte-dnd-action for cross-container DnD (D-10)
- On drop: call `trpc.tasks.update.mutate({ id, status: newColumn })` (or assignee/priority based on groupBy)
- Grouping (D-11): status=columns by status, assignee=rows per person, priority=rows per level, label=rows per label, sprint=separate section per sprint (sprint grouping hidden when methodology!='scrum')
- **Task type indicators on cards:** show type icon (epic=diamond, bug=bug-icon) on each TaskCard. Filter board by type via toolbar dropdown ("Show: All | Epics | Tasks | Bugs")
- **Subtask progress:** TaskCard shows subtask progress bar if task has children (e.g., "3/5 subtasks")
- WIP limits (D-12): each status column has configurable limit. When tasks.length > limit, column header turns red
- Density toggle (D-13): prop `density: 'compact'|'comfortable'` passed to TaskCard
- Swimlane UI: when groupBy != status, render horizontal swim lanes with status sub-columns
- Quick-create from column header (D-113): "+" button in each column header opens inline title input. Pre-fills status from that column. Enter creates, Esc cancels. Same QuickCreateTask component (from Plan 12) rendered inline.
- "My Work" as default view option (D-119): board/list toolbar has "My Work" toggle that filters to assignee=currentUser, grouped by Overdue/Due Today/This Week/No Due Date.
