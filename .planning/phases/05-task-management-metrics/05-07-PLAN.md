**CommentThread.svelte** (per D-01, D-03):
- Props: `{ taskId: string; orgId: string }`
- State: comments array, loading boolean
- Fetch via `trpc.comments.list.query({ taskId })`
- Render chronological flat list. Replies (parentCommentId non-null) indent under parent with `ml-8` margin.
- Each comment shows: author avatar, author name, timestamp, body (rendered via TipTap read-only), resolve button (if unresolved), reactions bar.
- Resolved comments collapse to single line (D-03): `[Resolved by {name}] {first_line}...` with expand toggle.
- `data-comment-thread` attribute on container.

**CommentComposer.svelte** (per D-02):
- Props: `{ taskId: string; parentCommentId?: string; onSubmit: (body) => void }`
- TipTap editor instance with extensions: StarterKit, Mention (user + team suggestions per D-101), TaskList, Placeholder("Write a comment...")
- Submit button. Keyboard: Cmd+Enter to submit.
- @mention suggestion popup: import `@tiptap/extension-mention`, configure suggestion with query function that searches org members + teams.
- On submit: call `onSubmit(editor.getJSON())`, clear editor.

**ReactionBar.svelte** (per D-04):
- Props: `{ commentId: string; reactions: Array<{ emoji: string; count: number; reacted: boolean }> }`
- Render row of emoji buttons with counts. 6 standard: 👍 👎 😄 🎉 😕 ❤️
- Click toggles reaction via `trpc.comments.addReaction`/`removeReaction`.
- "+" button to add new reaction from the 6 set.

**ActivityFeed.svelte** (per D-05):
- Props: `{ taskId: string }`
- Fetch events where subjectId=taskId via tRPC (events query or dedicated activity endpoint)
- Render timeline: each entry shows `{actor} changed {fieldName} from {fromValue} to {toValue}` with timestamp
- Status changes show colored chips for from/to. Assignment changes show avatar swap.
- `data-activity-feed` attribute.

**WatcherStack.svelte** (per D-07):
- Props: `{ taskId: string; watchers: Array<{ userId: string; source: string }> }`
- Render avatar stack (max 5 visible, +N overflow badge).
- Popover on click: full watcher list with source indicator.
- "Watch" / "Unwatch" toggle button for current user.
- Call `trpc.comments.subscribe`/`unsubscribe`.
