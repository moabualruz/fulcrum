**GanttView.svelte** (per D-60, D-61, D-62):
- Props: `{ projectId: string; groupBy?: "epic" | "assignee" | "sprint" }`
- Fetch tasks via tRPC: `trpc.tasks.list.query({ projectId, includeRelationships: true })`
- Map tasks to SVAR Gantt format:
  ```typescript
  const ganttTasks = tasks.map(t => ({
    id: t.id,
    text: t.title,
    start: t.startDate ? new Date(t.startDate) : new Date(),
    end: t.dueDate ? new Date(t.dueDate) : addDays(new Date(), 7),
    progress: t.status === 'completed' ? 100 : t.status === 'started' ? 50 : 0,
    // grouping
    parent: groupBy === 'epic' ? t.epicId : undefined,
  }));
  ```
- Map relationships to SVAR links (dependency arrows per D-21):
  ```typescript
  const links = relationships
    .filter(r => r.type === "blocks")
    .map(r => ({ source: r.fromTaskId, target: r.toTaskId, type: "e2s" }));
  ```
- SVAR Gantt props: `tasks={ganttTasks}`, `links={links}`, scales (day/week/month zoom per D-62)
- On task-update event (drag-to-reschedule): call `trpc.tasks.update({ id, startDate, dueDate })`
- On task click: open TaskDetailPanel (D-62)
- Grouping via `groupBy` prop → restructure task tree.
- `data-gantt-view` attribute on container.

**CriticalPathOverlay.svelte** (per D-102, D-103, D-104):
- Props: `{ tasks: GanttTask[]; relationships: TaskRelationship[] }`
- Calculate critical path using topological sort:
  1. Build DAG from "blocks" relationships
  2. Topological sort using Kahn's algorithm
  3. Forward pass: calculate earliest start/finish for each task
  4. Backward pass: calculate latest start/finish
  5. Critical tasks: those where earliest == latest (zero slack/float)
  6. Export `criticalTaskIds: string[]` and `slackMap: Map<string, number>` (float in days)
- Apply CSS class to critical path tasks in Gantt: `task-critical` → red/bold bar + red dependency arrows
- Non-critical tasks show slack as lighter-colored bar extension (per D-104)
- Recalculate on dependency/duration/schedule change (reactive via $derived)
- `data-critical-path` attribute.

Export critical path calculation as a pure function for reuse:
```typescript
export function calculateCriticalPath(tasks: Array<{id, startDate, dueDate}>, links: Array<{source, target}>): { criticalIds: string[]; slack: Map<string, number> }
```
