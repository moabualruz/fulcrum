**CriticalPath.ts** (D-102, D-103, D-104):
Pure TypeScript module (no Svelte -- unit testable):
```typescript
interface TaskNode { id: string; startDate: Date | null; dueDate: Date | null; duration: number; }
interface Relationship { sourceTaskId: string; targetTaskId: string; type: string; }
interface CriticalPathResult {
  criticalTaskIds: Set<string>;
  slack: Map<string, number>; // taskId -> slack days
}

export function computeCriticalPath(tasks: TaskNode[], relationships: Relationship[]): CriticalPathResult
```
- Algorithm: topological sort on 'blocks' relationships (D-102)
- Forward pass: compute earliest start/finish for each task
- Backward pass: compute latest start/finish
- Slack = latest_start - earliest_start
- Critical path = tasks with slack === 0
- Cache result: export a `cachedCriticalPath` reactive store that recomputes when tasks/relationships change (D-103)

    const { container } = render(GanttView, { props: { projectId: "test-1", groupBy: "epic" } });
    expect(container.innerHTML).toBeTruthy();
  });

  it("highlights critical path tasks in red", () => {
    // Unit test the algorithm directly
    const tasks = [
      { id: "a", startDate: new Date("2026-01-01"), dueDate: new Date("2026-01-03"), duration: 2 },
      { id: "b", startDate: new Date("2026-01-03"), dueDate: new Date("2026-01-05"), duration: 2 },
      { id: "c", startDate: new Date("2026-01-01"), dueDate: new Date("2026-01-02"), duration: 1 },
    ];
    const rels = [{ sourceTaskId: "a", targetTaskId: "b", type: "blocks" }];
    const result = computeCriticalPath(tasks, rels);
    expect(result.criticalTaskIds.has("a")).toBe(true);
    expect(result.criticalTaskIds.has("b")).toBe(true);
    // c has slack (not on critical path)
    expect(result.slack.get("c")).toBeGreaterThan(0);
  });
});
