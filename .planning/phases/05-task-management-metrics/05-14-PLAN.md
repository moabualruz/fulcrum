**src/cli/commands/report.ts** (D-82):
- Command: `fulcrum report <type> [options]`
- Types: burndown, burnup, velocity, cfd, cycle-time, lead-time, throughput, wip, workload, blocked, stale, progress
- Options: `--project <id>`, `--sprint <id>`, `--workspace` (scope selectors), `--format json|table|csv` (default: table), `--days <n>` (date range shortcut)
- Implementation: call tRPC report procedure based on type, format output:
  - `json`: JSON.stringify data
  - `table`: format as aligned ASCII table (simple column formatting)
  - `csv`: call exportCsv from tRPC
- All output to stdout for piping
- `--json` flag (D-82 shortcut): equivalent to `--format json`

**src/cli/commands/task-relate.ts** (HIGH-04 CLI surface):
- Command: `fulcrum task relate <taskId> <type> <otherTaskId>`
  - type: blocks, relates-to, duplicate-of
  - Calls `trpc.relationships.create.mutate({ sourceTaskId, targetTaskId, type })`
- `fulcrum task relate <taskId> --list`
  - Calls `trpc.relationships.listForTask.query({ taskId })`
  - Outputs as table: type, related task title, direction
- `fulcrum task relate <taskId> --delete <relationshipId>`
  - Calls `trpc.relationships.delete.mutate({ relationshipId })`
