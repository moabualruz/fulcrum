```typescript
// CLI: fulcrum report <type> [--sprint <id>] [--project <id>] [--format json|table|csv] [--days <n>]
```

Subcommands (one per report type):
- `fulcrum report burndown --sprint <id>` — calls reports.burndown
- `fulcrum report velocity --project <id> [--last <n>]` — calls reports.velocity
- `fulcrum report cycle-time --project <id> --days <n>` — calls reports.cycleTime
- `fulcrum report throughput --project <id> --days <n>` — calls reports.throughput
- `fulcrum report cfd --project <id> --days <n>` — calls reports.cfd
- `fulcrum report wip --project <id> --days <n>` — calls reports.wipOverTime
- `fulcrum report workload --project <id>` — calls reports.workload
- `fulcrum report stale --project <id> [--threshold <days>]` — calls reports.staleIssues
- `fulcrum report blocked --project <id>` — calls reports.blockedItems
- `fulcrum report capacity --sprint <id>` — calls reports.capacityUtilization

Format output:
- `--format json` (or `--json`): JSON array/object
- `--format table` (default): formatted ASCII table using column alignment
- `--format csv`: CSV with headers (calls reports.exportCsv)

All report commands use tRPC client to call reportsRouter.
