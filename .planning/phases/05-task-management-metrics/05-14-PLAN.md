**src/cli/commands/report.ts** (D-82):
- Command: `fulcrum report <type> [options]`
- Types: burndown, burnup, velocity, cfd, cycle-time, lead-time, throughput, wip, workload, blocked, stale, progress
- Options: `--project <id>`, `--sprint <id>`, `--workspace` (scope selectors), `--format json|table|csv` (default: table), `--days <n>` (date range shortcut)
- Implementation: call tRPC report procedure based on type, format output:
  - `json`: JSON.stringify data
  - `table`: format as aligned ASCII table (simple column formatting)
  - `csv`: call exportCsv from tRPC
- All output to stdout for piping
- `--json` flag (D-82 shortcut): equivalent to `--format json`

**src/cli/commands/task-relate.ts** (HIGH-04 CLI surface):
- Command: `fulcrum task relate <taskId> <type> <otherTaskId>`
  - type: blocks, relates-to, duplicate-of
  - Calls `trpc.relationships.create.mutate({ sourceTaskId, targetTaskId, type })`
- `fulcrum task relate <taskId> --list`
  - Calls `trpc.relationships.listForTask.query({ taskId })`
  - Outputs as table: type, related task title, direction
- `fulcrum task relate <taskId> --delete <relationshipId>`
  - Calls `trpc.relationships.delete.mutate({ relationshipId })`

**src/cli/commands/task-hierarchy.ts** (task type + hierarchy CLI):
- `fulcrum task create` enhanced: `--type epic|task|subtask|bug` (default: task), `--parent <taskId>` (sets parent_id, auto-sets type to subtask if parent provided and no explicit --type)
- `fulcrum task list` enhanced: `--type <type>` filter, `--parent <taskId>` shows children only
- `fulcrum task tree <taskId>`: display hierarchy tree using box-drawing characters:
  ```
  ◆ Epic: User Authentication (epic)
  ├── Task: Login page (task)
  │   ├── Subtask: Form validation (subtask) ✓
  │   └── Subtask: OAuth integration (subtask)
  └── Task: Password reset (task)
  ```
  Fetches via `trpc.tasks.list.query({ parentId })` recursively (max 3 levels)

**src/cli/commands/comment.ts** (threaded comments CLI):
- `fulcrum comment list <taskId>`: fetches `trpc.comments.threaded.query({ taskId })`, renders with indent:
  ```
  @alice (2h ago): First comment
    ↳ @bob (1h ago): Reply to alice
      ↳ @alice (30m ago): Thanks!
  @charlie (1h ago): Another top-level
  ```
  Threaded replies indent with `  ↳ ` prefix per nesting level (max 3)
- `fulcrum comment add <taskId> "body text"`: calls `trpc.comments.create.mutate({ taskId, body: plainTextToTipTap(text) })`
- `fulcrum comment reply <commentId> "body text"`: calls `trpc.comments.create.mutate({ taskId, body, parentCommentId })`
- `fulcrum comment resolve <commentId>`: calls `trpc.comments.resolve.mutate`

**src/cli/commands/project-config.ts** (methodology + hierarchy config CLI):
- `fulcrum project config <projectId>`: display current config:
  ```
  Methodology: kanban
  Enabled types: epic, task, subtask, bug
  Workflow: 4 transitions configured
  ```
- `fulcrum project config <projectId> --methodology scrum|kanban|none`: calls `trpc.workflows.updateMethodology.mutate`
- `fulcrum project config <projectId> --types epic,task,subtask,bug`: calls `trpc.workflows.updateEnabledTaskTypes.mutate`
- All output piped to stdout, `--json` flag for machine consumption

**src/cli/commands/import.ts** (D-121):
- Command: `fulcrum import <source> --project <id> [--dry-run] [--json]`
- Sources: `jira`, `github`, `trello`, `csv` (extending existing linear importer pattern)

- For API sources: prompts for auth token (or reads from env `FULCRUM_JIRA_TOKEN` etc.)
- `--dry-run`: shows what would be imported without creating tasks
- Uses existing `src/importers/` pattern (Importer interface, ImportedTask shape)
- Dedup via externalId field. Progress output: "Imported 45/120 tasks..."

**src/cli/commands/export.ts** (D-120):
- Command: `fulcrum export tasks --project <id> --format csv|json [--filter <ast>]`
- Calls `trpc.reports.exportCsv` or `trpc.tasks.list` with format
- CSV: columns = title, id, status, priority, assignee, labels, due_date, points, custom fields
- JSON: full task objects
- Outputs to stdout for piping: `fulcrum export tasks --project abc --format csv > tasks.csv`
