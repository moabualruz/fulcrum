- Connects WebsocketProvider to y-websocket server: `new WebsocketProvider('ws://localhost:PORT/yjs', taskId, ydoc)`
- TipTap extensions config (to be used when TaskDetailPanel description editor initializes):
  ```typescript
  export function getCollaborationExtensions(taskId: string, user: { name: string; color: string }) {
    const ydoc = new Y.Doc();
    const provider = new WebsocketProvider("ws://localhost:1234/yjs", `task-${taskId}`, ydoc);
    return [
      Collaboration.configure({ document: ydoc }),
      CollaborationCursor.configure({
        provider,
        user: { name: user.name, color: user.color },
      }),
    ];
  }
  ```
