**BurndownChart.svelte** (D-35):
- Props: `data: {date: string, remaining: number, ideal: number}[]`
- LayerChart LineChart with two series: actual (chart-1) + ideal (chart-2 dashed)
- Vertical jumps for scope changes visible naturally in line breaks

**VelocityChart.svelte** (D-37):
- Props: `data: {sprint: string, completed: number, average: number}[]`
- LayerChart BarChart for completed per sprint + LineChart overlay for rolling average
- Bar color: green if >= average, amber if below

**CfdChart.svelte** (D-39):
- Props: `data: {date: string, [status: string]: number}[]`
- LayerChart AreaChart with `stack` layout — one area per status category
- Colors: backlog=chart-1, unstarted=chart-2, started=chart-3, completed=chart-4, canceled=chart-5

**CycleTimeChart.svelte** (D-40):
- Props: `data: {taskId: string, completedAt: string, cycleTimeHours: number}[]`, `percentiles: {p50, p75, p95}`
- LayerChart ScatterChart: dots per task (x=date, y=hours)
- Percentile reference lines at p50, p75, p95 (D-40 bands)

**ThroughputChart.svelte** (D-42):
- Props: `data: {week: string, completed: number, average: number}[]`
- LayerChart BarChart + rolling average line

**WipChart.svelte** (D-43):
- Props: `data: {date: string, wipCount: number, limit?: number}[]`
- LayerChart AreaChart with optional limit reference line (red when exceeded)

**ForecastChart.svelte** (D-105, D-106, D-107, D-108):
- Props: `remaining: number`, `throughputHistory: number[]`, `targetDate?: string`
- Client-side Monte Carlo (D-108): run 1000 iterations sampling from throughputHistory distribution. For each iteration: simulate daily completions until remaining=0, record completion date.
- Compute p50, p75, p85, p95 completion dates
- Render fan chart: LayerChart AreaChart with 4 layered opacity bands (p50 darkest → p95 lightest)
- Props include scopeLabel for "Sprint X" or "Epic Y" display (D-107)
- Computation runs in `$effect` or `onMount` — pure math, ~10ms for 1000 iterations

**ReportDatePicker.svelte** (D-55):
- Props: `value: {start: Date, end: Date}`, `onChange`
- Quick presets: Last 7/14/30/90 days, This sprint, Custom range
- Custom range uses shadcn-svelte Calendar/Popover components
