**WorkflowService.ts:**
- Constructor(em: EntityManager)
- `getTransitionGraph`: query Project entity by projectId+orgId, return `workflowConfig.transitions` (adjacency list: `Record<string, string[]>`)
- `updateTransitions`: update Project.workflowConfig with new transitions object, flush
- `validateTransition`: look up graph, check if `toStatus` is in `graph[fromStatus]` array. If no graph configured (empty), allow all transitions (permissive default).
- `getDefaultWorkflow(methodology)`: return transitions for D-23 default set based on methodology:
  - `scrum`: Backlog→Todo, Todo→InProgress, InProgress→InReview, InReview→Done, any→Canceled, Canceled→Backlog
  - `kanban`: Backlog→InProgress, InProgress→InReview, InReview→Done, any→Canceled (no sprint-bound "Todo" intermediary — tasks flow continuously)
  - `none`: empty graph (all transitions allowed — no guards, simple task list mode)
- `getMethodology`: query project by id, return `methodology` column value
- `updateMethodology`: set project.methodology, optionally reset workflow_config to new methodology's defaults (ask via param `resetWorkflow: boolean`)
- `getEnabledTaskTypes`: query project.enabled_task_types jsonb array
- `updateEnabledTaskTypes`: validate types against TASK_TYPES from schemas.ts, update project.enabled_task_types
- Emit event on transition validation failure for audit.

**RelationshipService.ts** (HIGH-04 fix — full CRUD):
- Constructor(em: EntityManager)
- `create`: validate sourceTaskId != targetTaskId, validate both tasks exist in org, if type='blocks' run checkCycle, create TaskRelationship entity, flush. Emit `relationship.created` event.
- `delete`: find by id + orgId, remove, flush. Emit `relationship.removed` event.
- `listForTask`: find where sourceTaskId=taskId OR targetTaskId=taskId, with orgId scope
- `listBlockers`: find where targetTaskId=taskId AND type='blocks', return source tasks
- `checkCycle`: BFS/DFS from targetId following `blocks` relationships (source→target edges). If sourceId is reachable, cycle exists. Max depth 50 to prevent infinite traversal.
- `getBlockedItems`: find all tasks where they appear as targetTaskId in a 'blocks' relationship, filter to projectId scope
- `listBlockedBy(orgId, taskId)` (D-123): find where sourceTaskId=taskId AND type='blocks' — returns tasks that THIS task blocks (the reverse direction of listBlockers)
- `markAsDuplicate(orgId, sourceId, targetId, opts)` (D-122): create `duplicate_of` relationship. If opts.autoClose: set source task status to project's canceled-category status. If opts.transferWatchers: query source watchers, upsert into target with source='duplicate_merge'. Emit `relationship.created` event with metadata `{autoClose, transferWatchers}`.

**TemplateService.ts** (D-115):
- Constructor(em: EntityManager)
- `create(orgId, projectId, data)`: create TaskTemplate entity, flush
- `list(orgId, projectId)`: find templates where (projectId matches OR projectId IS NULL for workspace-scoped), scoped to org
- `apply(orgId, templateId, overrides?)`: load template, return merged fields (templateData + overrides). Does NOT create task — caller (TaskService) uses returned data.
- `delete(orgId, templateId)`: remove entity
- `setDefault(orgId, projectId, templateId)`: clear existing defaults for scope, set this one's isDefault=true

**RecurrenceService.ts** (D-116):
- Constructor(em: EntityManager, taskService: TaskService)
- `create(orgId, sourceTaskId, config)`: validate config (cron OR interval required based on triggerType). Snapshot current task fields into template_data. Calculate next_run_at from cron/interval. Create TaskRecurrenceRule entity.
- `processDue()`: called by graphile-worker job. Query rules where `next_run_at <= now() AND enabled = true`. For each: clone task via TaskService.create using template_data, increment occurrences_created, check bounds (max_occurrences, end_date), calculate + set next next_run_at. If bounds exceeded, set enabled=false.
- `onTaskComplete(orgId, taskId)`: query rules where sourceTaskId=taskId AND triggerType='on_complete' AND enabled=true. Schedule next occurrence (set next_run_at = now + interval_days).
- `delete(orgId, ruleId)`: remove rule
- `list(orgId, taskId)`: return rules for sourceTaskId

export const workflowsRouter = t.router({

    .query(/* WorkflowService.validateTransition — returns {allowed, reason?} */),

  getDefault: permissionedProcedure({ resource: "workflows", action: "list" })
    .input(z.object({ methodology: z.enum(["scrum", "kanban", "none"]).optional() }))
    .query(/* WorkflowService.getDefaultWorkflow(methodology) */),

  getMethodology: permissionedProcedure({ resource: "workflows", action: "list" })
    .input(z.object({ projectId: z.string().uuid() }))

    .mutation(/* WorkflowService.updateMethodology */),
