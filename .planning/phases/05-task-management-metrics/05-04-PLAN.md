**WorkflowService.ts:**
- Constructor(em: EntityManager)
- `getTransitionGraph`: query Project entity by projectId+orgId, return `workflowConfig.transitions` (adjacency list: `Record<string, string[]>`)
- `updateTransitions`: update Project.workflowConfig with new transitions object, flush
- `validateTransition`: look up graph, check if `toStatus` is in `graph[fromStatus]` array. If no graph configured (empty), allow all transitions (permissive default).
- `getDefaultWorkflow`: return hardcoded transitions for D-23 default set: Backlog→Todo, Todo→InProgress, InProgress→InReview, InReview→Done, any→Canceled, Canceled→Backlog.
- Emit event on transition validation failure for audit.

**RelationshipService.ts** (HIGH-04 fix — full CRUD):
- Constructor(em: EntityManager)
- `create`: validate sourceTaskId != targetTaskId, validate both tasks exist in org, if type='blocks' run checkCycle, create TaskRelationship entity, flush. Emit `relationship.created` event.
- `delete`: find by id + orgId, remove, flush. Emit `relationship.removed` event.
- `listForTask`: find where sourceTaskId=taskId OR targetTaskId=taskId, with orgId scope
- `listBlockers`: find where targetTaskId=taskId AND type='blocks', return source tasks
- `checkCycle`: BFS/DFS from targetId following `blocks` relationships (source→target edges). If sourceId is reachable, cycle exists. Max depth 50 to prevent infinite traversal.
- `getBlockedItems`: find all tasks where they appear as targetTaskId in a 'blocks' relationship, filter to projectId scope

**Tests:**
- WorkflowService: test validate allows configured transitions, rejects unconfigured, permissive when no config
- RelationshipService: test create succeeds, test create rejects self-reference, test cycle detection catches A→B→A, test listForTask returns both directions, test getBlockedItems

```typescript
export const workflowsRouter = t.router({
  getTransitions: permissionedProcedure({ resource: "workflows", action: "list" })
    .input(z.object({ projectId: z.string().uuid() }))
    .query(/* WorkflowService.getTransitionGraph */),

  updateTransitions: permissionedProcedure({ resource: "workflows", action: "update" })
    .input(z.object({ projectId: z.string().uuid(), transitions: z.record(z.array(z.string())) }))
    .mutation(/* WorkflowService.updateTransitions */),

  validateTransition: permissionedProcedure({ resource: "workflows", action: "list" })
    .input(z.object({ projectId: z.string().uuid(), fromStatus: z.string(), toStatus: z.string() }))
    .query(/* WorkflowService.validateTransition — returns {allowed, reason?} */),

  getDefault: permissionedProcedure({ resource: "workflows", action: "list" })
    .query(/* WorkflowService.getDefaultWorkflow */),
});
```
