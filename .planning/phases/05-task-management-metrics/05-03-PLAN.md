Create `src/services/CommentService.ts` following TaskService pattern (per D-01..D-09):

**Constructor:** `constructor(private readonly em: EntityManager) {}`

**Comment methods:**
- `list(orgId, taskId)` — find TaskComment where org=orgId, taskId, orderBy createdAt ASC. Include reactions via separate query on CommentReaction.
- `create(orgId, input: { taskId, authorId, body: Record<string,unknown>, parentCommentId?: string })` — create TaskComment, emit `task.comment_added` event (using Event entity with verb, subjectKind:"task", subjectId), auto-subscribe author as watcher with source "create" if not already watching. Parse body for @mentions using `extractMentions(body)` helper — for each mentioned userId, call `subscribe(orgId, taskId, userId, "mention")`.
- `resolve(orgId, commentId, resolvedBy)` — find comment, set resolved=true, resolvedBy, resolvedAt=now(), emit `task.comment_resolved` event.
- `unresolve(orgId, commentId)` — set resolved=false, resolvedBy=null, resolvedAt=null.
- `delete(orgId, commentId)` — find and remove. Also remove associated CommentReaction rows.

**Reaction methods:**
- `addReaction(orgId, commentId, userId, emoji)` — create CommentReaction (unique constraint handles duplicates — catch UniqueConstraintViolationException, return { added: false }).
- `removeReaction(orgId, commentId, userId, emoji)` — find and remove.
- `listReactions(orgId, commentId)` — find all CommentReaction for comment, group by emoji with user counts.

**Watcher methods:**
- `subscribe(orgId, taskId, userId, source: "manual"|"mention"|"assign"|"create")` — create TaskWatcher if not exists (check unique first to avoid constraint violation).
- `unsubscribe(orgId, taskId, userId)` — find and remove TaskWatcher.
- `listWatchers(orgId, taskId)` — find all TaskWatcher for task.
- `isWatching(orgId, taskId, userId)` — return boolean.

**Helper:**
- `extractMentions(body: Record<string,unknown>): string[]` — walk TipTap JSON tree looking for nodes with `type: "mention"` and extract `attrs.id` as user IDs. Return unique array of user IDs.

**Event emission:** Follow `emitTaskEvent` pattern from TaskService — create Event entity with org ref, persist (no flush — outer boundary handles it). Use D-34 fields: fieldName="comment", fromValue=null, toValue={ commentId, authorId }.

All queries MUST filter `{ org: orgId, ... } as never` for IDOR prevention.

After implementation, update `src/services/CommentService.test.ts` to make tests pass with real assertions against the service (using test EM or mocks matching project test conventions).
