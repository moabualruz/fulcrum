## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, tree indent unit |
| sm | 8px | Compact element spacing, toolbar button gaps |
| md | 16px | Default element spacing, card padding, editor toolbar height |
| lg | 24px | Section padding, panel gaps, sidebar padding |
| xl | 32px | Layout gaps, search result list spacing |
| 2xl | 48px | Major section breaks, empty state vertical centering offset |
| 3xl | 64px | Page-level spacing |

Exceptions:
- Touch targets (Cmd+K items, tree nodes): minimum 44px height
- Doc tree nesting indent: 12px per level (3 * xs — deliberate exception for compact tree)
- TipTap editor content area: 40px horizontal padding on desktop, 16px on mobile

## Typography

Declared type scale — 4 sizes, 2 weights:

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px | 400 | 1.5 | Search results body snippet, memory list rows, comment text |
| Label | 12px | 400 | 1.4 | Facet chip labels, badge text, toolbar button labels, tree node meta |
| Heading | 20px | 600 | 1.3 | Panel headings, doc title in version timeline, section headers |
| Display | 28px | 600 | 1.2 | Doc title in editor header, page-level empty state heading |

Font: `Inter Variable` — use `font-sans` Tailwind alias (maps to `--font-sans`).

Prose-content exception (scoped to `.ProseMirror` only — not a system token): 16px / 400 / 1.6 — applied via scoped CSS override inside the TipTap editor canvas for reading comfort. Not a declared type scale size.

## Color

All values from `src/web/src/app.css` OKLCH tokens. No new colors introduced.

| Role | Token | Light value | Usage |
|------|-------|-------------|-------|
| Dominant (60%) | `--background` | oklch(1 0 0) — white | App background, editor canvas |
| Secondary (30%) | `--card` / `--sidebar` | oklch(1 0 0) / oklch(0.985 0 0) | Doc sidebar, search panel, memory browser panel, version timeline panel |
| Accent (10%) | `--primary` | oklch(0.205 0 0) — near-black | Reserved — see list below |
| Destructive | `--destructive` | oklch(0.577 0.245 27.325) — red | Delete doc, delete memory, delete saved search only |
| Muted | `--muted-foreground` | oklch(0.556 0 0) | Snippet text, metadata, timestamps, empty state body |
| Diff added | green-600 / `#16a34a` | — | Version diff inline additions (prosemirror-changeset) |
| Diff removed | red-600 / `#dc2626` | — | Version diff inline deletions (prosemirror-changeset) |

**Accent (`--primary`) reserved for:**
- Active Cmd+K palette item highlight (background tint)
- Search result title match highlight
- Version timeline "current version" indicator dot
- Memory promotion toggle (active state)
- Primary CTA buttons (Save, Restore, Promote, Search)

Accent is NOT used for: hover states on nav items, icon fills, decorative elements, all interactive elements generically.

Dark mode: tokens already defined in `.dark {}` block in `app.css` — use same token names, dark values apply automatically.

## Interaction Contracts

### TipTap Editor

- Toolbar: fixed top, 48px height, `--border` bottom edge, `--secondary` background
- Toolbar presets per `doc_type`: each type shows/hides button groups — do not show same toolbar for all types
- Save: Cmd+S triggers save; shows sonner toast "Saved" (1.5s, bottom-right)
- Save pending indicator: dot in tab title or header area (not a blocking modal)
- Unsaved changes: `·` prefix on doc title in sidebar tree node

### Doc Tree (DocsSidebar)

- Drag handle: appears on row hover (opacity 0 → 1), 16px wide, `grip-vertical` lucide icon
- Drop target: 2px `--primary` horizontal line between nodes, 0px at root borders
- Nesting: indent 12px per level; chevron icon for expand/collapse
- Tree node height: 32px; active node: `--secondary` background + `--primary` left border 2px
- New doc button: `+` icon at tree header row, opens inline name input (not modal)

### Version Timeline (DocVersionTimeline)

- Trigger: "History" button in editor toolbar, opens sheet from right, 360px wide
- List item: timestamp (relative, e.g. "3 hours ago") + author avatar (16px) + restore button
- Current version: `--primary` filled circle indicator, "Current" label, no restore button
- Inline diff: toggle "Show diff" per version item; renders green/red inline using `prosemirror-changeset`
- Restore: button label "Restore this version"; confirmation: inline confirm row (not dialog) — "Restore? [Confirm] [Cancel]"

### Inline Doc Comments

- Trigger: select text in editor → tooltip "Add comment" appears (popover anchor, 200ms delay)
- Comment icon: `message-circle` lucide, 16px, appears in right gutter at anchor line
- Panel: slides in from right (not sheet — inline panel, 300px, pushes editor content)
- Threading: reply indented 24px under parent, max 2 levels
- Resolve: checkmark button on comment header; resolved comments collapse to 1-line "Resolved" summary
- Anchor highlight: `--muted` background tint on anchored text range

### Search Page

- Layout: left panel (facets, 240px fixed) + right panel (results, flex-1)
- Search input: full-width at top, 48px height, `search` lucide prefix icon, clears on Escape
- Facet chips: horizontal row below search input; active chip uses `--primary` fill; inactive uses `--secondary`
- Result row: 72px height; title (14px/600) + snippet (14px/400/muted) + kind badge + timestamp
- Match highlight: `--primary` text color on matched terms in title and snippet (not background highlight)
- Empty state: centered illustration (none — use icon only), heading "No results", body "Try different keywords or adjust filters"
- Results tabs: All / Docs / Tasks / Memories / Runs / Artifacts — tabs component, count badge per tab
- Saved search: `bookmark` icon button at search input right; opens dropdown to name + save

### Cmd+K Palette (extension)

- Sections: "Navigation" / "Create" / "Bulk Actions" (context-dependent) / "Search Results"
- Section header: 12px/400/muted-foreground, 8px top padding
- Command item height: 44px; keyboard highlight: `--secondary` background
- Search results section: appears below commands when input has 2+ chars; separated by `separator` component
- Bulk actions section: only visible when `selectedTaskIds.length > 0` (reads from Svelte store)
- Keyboard: arrow up/down navigate items; Enter dispatches; Escape closes; Tab jumps sections

### Memory Browser

- Layout: table view; columns: Body (truncated 2 lines) / Importance / Project / Global / Actions
- Importance badge: high=`--primary` fill, medium=`--secondary` fill+border, low=outline only
- Global toggle: `MemoryPromoteToggle` — toggle button, active state uses `--primary`, shows "Global" label
- Promote confirmation: inline in row (not dialog) — "Promote to global? [Yes] [Cancel]"
- Empty state: "No memories yet. Run an agent task to generate memories."
- Search within browser: `InContextSearchBar` (already exists in `src/web/src/lib/components/docs/`)
