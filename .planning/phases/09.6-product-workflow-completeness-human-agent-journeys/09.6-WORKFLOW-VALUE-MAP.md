## Non-Negotiable Value

The replacement is not done when CRUD screens exist. It is done when the full loop works:

1. User starts freeform docs or guided ACP.
2. Freeform docs become planning context later.
3. Planning produces technical plan plus prototype and boilerplate.
4. User reviews plan/prototype/code-like intent with annotation feedback loops.
5. Approval writes docs, tasks, goals, phases, success criteria, and executable work breakdown.
6. Project management works without AI and becomes stronger with AI.
7. Boards/tasks expose dependency-aware run buttons.
8. Agents run dependency trees, self-check against task success criteria, and loop with QA/review agents.
9. Final QA checks all docs and success criteria.
10. User is prompted for UAT and code review loops.
11. Approved UAT/code review becomes real-data E2E regression tests.
12. User can continue by editing docs or ACP state and repeat the cycle.

## Copy/Adapt Ordering

1. ACP bridge/session/permission/traffic primitives, because they unblock guided planning and agent sessions.
2. Plannotator plan/review primitives, because they define approval and feedback semantics.
3. Docmost docs/editor/collaboration primitives, because docs are the context root.
4. Plane PM model and workbench primitives, because approved plans become tracked work.
5. Fusion dependency/run/review primitives, because tasks become executable agent work.
6. CLI/TUI parity surfaces for each service after the server/service contract exists.
7. Real-data E2E generation after UAT/code-review approval semantics exist.
