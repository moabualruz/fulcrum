<objective>
Rebuild Web IA around project-first workflow. Topbar owns hierarchy picker; sidebar is contextual; command palette is scoped; default density is balanced/minimal; Advanced mode exposes operational detail without changing permissions.
</objective>

<decision_coverage>
D-01, D-02, D-03, D-05, D-18, D-19, D-20, D-21, D-22, D-23, D-24, D-25, D-40, D-45, D-46, D-47, D-48, D-50, D-53.
</decision_coverage>

<technical_decisions>
- Follow `09.6-UI-SPEC.md` screen contracts.
- Topbar: hierarchy picker, breadcrumb, scope indicator, scoped Cmd-K, health indicators, Default/Advanced density switch.
- Sidebar groups: Current Scope, Portfolio, System. Sidebar must not become giant portfolio tree.
- Cmd-K scopes mutations to current project/subproject by default with visible override.
- Use existing local Svelte/shadcn/Bits-style primitives. No new UI kit.
- Cards only for repeated items/modals/framed tools; operational pages use full-width bands/unframed layouts.
</technical_decisions>

<threat_model>
Threats:
- UI lets user mutate wrong scope. Mitigation: scope chip and target confirmation for parent aggregate actions.
- Advanced mode exposes unsafe action without policy. Mitigation: density affects presentation only; action availability still service policy.
- Command palette creates global/orphan records. Mitigation: command generator requires scope or explicit All projects override.
</threat_model>
