# Phase 09.6 Copy/Adapt Matrix

This is the Phase 3 decision matrix. It decides what to copy/adapt, what to study only, and what to omit for now before any upstream source lands in Fulcrum production paths.

Rules:

- Do not track `.scratch/upstream-product-replacement/**`.
- Do not create tracked `vendor-src/**` or equivalent archive folders.
- Copy/adapt source only into real Fulcrum paths.
- Every copied/adapted production file must carry provenance metadata when copied in Phase 4.
- "Copy/adapt" means preserve source behavior and tests, then adapt imports/framework/data model.
- "Port" means direct file copy is blocked by language/framework, but upstream code remains the behavioral source and tests/specs must be preserved as upstream-derived tests.

## Decision Key

| Decision | Meaning |
|---|---|
| Copy/adapt | Bring upstream code into real Fulcrum source/test paths and adapt it. |
| Port from source | Direct file copy is blocked by language/runtime, but behavior/data/test expectations are ported with source provenance. |
| Study only | Keep upstream in ignored scratch for design/behavior reference; no production copy in initial slices. |
| Omit for now | Not required for the user's workflow; preserve in scratch and record reason. |
