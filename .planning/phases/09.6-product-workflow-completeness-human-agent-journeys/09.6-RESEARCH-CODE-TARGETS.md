## Web Targets

### Product shell and navigation

Problem:

- `apps/web/src/routes/+layout.svelte` owns static `paletteItems`.
- `apps/web/src/lib/components/app/nav-data.ts` is separate and grouped but still domain-led.

Required edits:

- Move palette item generation out of `+layout.svelte`.
- Add project-aware command generator.
- Add project-first nav source of truth.
- Sidebar groups depend on active project:
  - Current Project
  - Portfolio
  - System
- Global pages display `All projects` state.
