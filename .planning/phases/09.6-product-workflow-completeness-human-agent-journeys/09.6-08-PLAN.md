<threat_model>
Threats:
- False completion from route/unit tests only. Mitigation: H1-H6/A1-A5 journey suites block completion.
- Fixture diverges per client. Mitigation: shared fixture IDs and API parity assertions.
- Graph/docs overstate reality. Mitigation: docs updated after tests pass; graphify regenerated from current code.
- Real agent run mutates unsafe workspace during UAT. Mitigation: optional run uses scratch repo, explicit policy/trust mode, dry-run where possible.
</threat_model>
