# Phase 9.5 Gray Areas

Date: 2026-05-06

## Purpose

This document lists unresolved architecture gray areas that must be deeply researched, spiked, and decided before Phase 9.5 implementation can be trusted.

No gray area may be skipped.

Each item needs:

- Current repo evidence.
- External research where relevant.
- Options.
- Tradeoffs.
- Recommendation.
- Spike/proof if risky.
- Decision owner/status.

Status labels:

- `OPEN`
- `RESEARCHING`
- `SPIKE REQUIRED`
- `DECIDED`
- `BLOCKED`

## G-001 Backend/API Framework

Status: OPEN

Question:

- Should Fulcrum use Hono, NestJS, Elysia, Fastify, tRPC-only, SvelteKit-only adapters, Effect Platform, GraphQL, Encore.ts, or a hybrid?

Must research:

- Bun compatibility.
- Local-first PGlite/PostgreSQL support.
- DI/container story.
- Testing story.
- OpenAPI story.
- Type safety story.
- Security middleware/authz story.
- CLI/TUI reuse story.
- Migration cost from current code.

## G-002 Application Layer Shape

Status: OPEN

Question:

- What exact module/file structure owns commands, queries, schemas, DTOs, errors, events, and transactions?

Candidate:

```text
src/application/<domain>/
  <domain>.commands.ts
  <domain>.queries.ts
  <domain>.service.ts
  <domain>.schema.ts
  <domain>.dto.ts
  <domain>.errors.ts
```

Gray area:

- Whether services remain classes, pure functions, Effect services, or Nest providers.
