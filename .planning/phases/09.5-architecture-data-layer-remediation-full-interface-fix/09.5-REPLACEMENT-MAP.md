## Non-Destructive Retirement Rule

Legacy `src/product-kernel/store/*` files remain as compatibility shims or test fixtures until all runtime interface imports point at `src/application/**`. No ProductDb-backed function should be called from `apps/web`, `apps/cli/src`, `apps/tui/src`, `apps/server/src/api`, `apps/server/src/router`, or `apps/server/src/runtime/trpc` after Plan 06 green tasks.
