## Sampling Rate

- **After every RED test task:** run `bun run ci --tier=quick` plus the focused test file.
- **After every GREEN implementation task:** run the focused test file and `bun run ci --tier=unit --domain={domain}`.
- **After every plan wave:** run `bun run ci --tier=integration`.
- **Before `$gsd-verify-work`:** run `FULCRUM_RUN_E2E=1 bun run ci`.
- **Max feedback latency:** 180 seconds for non-full feedback.
