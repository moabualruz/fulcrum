# Phase 9.5: UAT Baseline — Minimum Passing Criteria

**Created:** 2026-05-06
**Source:** 22 SPEC requirements + cross-phase audit + prior UAT backlog
**Current test inventory:** 562 web, 44 CLI, 18 TUI, 8 services, 7 router, 4 DB, 17 E2E Playwright

This document defines the **bare minimum** test baseline Phase 9.5 must achieve before closure. It guides writing unit tests, component tests, integration tests, and E2E tests across all interfaces.

---

## Test Pyramid Strategy

```
                    ┌─────────────┐
                    │  E2E (PW)   │  Web: Playwright
                    │  E2E (CLI)  │  CLI: bun test + child_process
                    │  E2E (TUI)  │  TUI: bun test + render snapshots
                    ├─────────────┤
                    │ Integration │  Application → MikroORM → PGlite
                    │   Tests     │  tRPC caller → application → DB
                    ├─────────────┤
                    │  Component  │  Web: vitest + @testing-library/svelte
                    │   Tests     │  TUI: vitest + widget render
                    ├─────────────┤
                    │    Unit     │  Application commands/queries
                    │   Tests     │  Error mapping, validation, DTOs
                    └─────────────┘
```

### Tools by Interface

| Interface | Unit/Component | Integration | E2E |
|-----------|---------------|-------------|-----|
| **Web** | vitest + @testing-library/svelte | vitest + MikroORM + PGlite | Playwright |
| **CLI** | bun:test | bun:test + `createLocalCaller()` + PGlite | bun:test + `child_process.exec('fulcrum ...')` |
| **TUI** | bun:test + render snapshots | bun:test + `buildCaller()` + PGlite | bun:test + screen output assertions |
| **API** | bun:test | bun:test + Hono `app.fetch()` + PGlite | supertest or xh against running server |
| **Application** | bun:test (pure logic) | bun:test + MikroORM EM + PGlite | N/A (covered by interface E2E) |
