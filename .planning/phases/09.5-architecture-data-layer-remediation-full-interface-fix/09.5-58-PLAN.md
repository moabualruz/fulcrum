# Plan 58: Interface Boundary Gap Closure

## Gaps

- CLI import/export still bootstrapped ORM/runtime objects instead of using API invocation.
- Web docs/search components imported DB/product-kernel types directly.
- Web task detail helper owned SQL/data mutation logic inside web server code.
- Web passkey route loaded ORM/auth service directly from route-local code.
- CLI db and interactive init commands owned raw SQL/migration/seed manipulation.
- Boundary tests missed `.svelte` files and generic `execute<T>()` raw SQL calls.
- Review finding WR-03 kept full web E2E hidden behind `FULCRUM_RUN_E2E=1`.

## Decisions

- Interface layers call `createLocalCaller` or import application services only.
- Data access, raw SQL, seeding, and migration status live under `src/application/**` or explicit runtime adapter modules.
- Web-local task detail file remains a compatibility re-export only.
- Boundary tests must scan Svelte sources and wider raw SQL call shapes.
- Full E2E is a normal CI e2e step, not an env-hidden optional check.

## Implementation Tasks

- Replace CLI import/export local ORM bootstrap with `createLocalCaller({ requireSession: true })`.
- Move task detail SQL/mutations from `src/web/src/lib/server/task-detail.ts` to `src/application/tasks/task-detail.ts`.
- Move passkey auth context loading to `src/application/auth/passkey-context.ts`.
- Move CLI db migration status/application logic to `src/application/db/commands.ts`.
- Move interactive init seed logic/errors to `src/application/init/**`.
- Replace web-facing DB/product-kernel type imports with domain/application types.
- Harden `src/architecture/boundary.test.ts` and `src/architecture/no-raw-sql.test.ts`.
- Remove `FULCRUM_RUN_E2E` skip behavior from `scripts/ci.ts` and update `scripts/ci.test.ts`.

## Verification

- Interface scan must report no business logic/direct ORM hits in `src/web/src/routes`, `src/web/src/lib`, `src/cli`, or `src/tui` except composition-root type references.
- Boundary, raw-SQL, migration, task detail, and page-server tests must pass.
- `bun run lint:boundaries` must pass.
- Typecheck must pass.
- Latest Symphony sync/conformance gates must pass.
