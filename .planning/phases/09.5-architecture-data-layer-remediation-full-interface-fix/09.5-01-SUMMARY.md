### Auto-fixed Issues

**1. [Rule 1 - Bug] Replaced leaking Bun module mocks in adapter tests**

- **Fix:** Added adapter-local `__setTaskApplicationForTest` and `__setKernelTaskApplicationForTest` hooks.
- **Files modified:** `src/server/trpc/routers/tasks.ts`, `src/api/routes/kernel-tasks.ts`, `src/server/trpc/routers/tasks.test.ts`, `src/api/routes/kernel-tasks.test.ts`
- **Verification:** `bun test src/server/trpc/routers/tasks.test.ts src/api/routes/kernel-tasks.test.ts`
- **Committed in:** `83b74b00`

**2. [Rule 1 - Bug] Defaulted lazy task dependencies during DTO serialization**
- **Found during:** Task 09.5-01-04
- **Issue:** A task loaded without populated dependency relations serialized `dependencies` as `undefined`, causing tRPC output validation to reject an application-created task.
- **Fix:** `serializeTask` now emits `{ blocks: [], blocked_by: [] }` when dependency relations are not populated.
- **Files modified:** `src/application/tasks/queries.ts`, `src/application/tasks/interface-parity.test.ts`
- **Verification:** `bun test src/application/tasks/interface-parity.test.ts`
- **Committed in:** `8be9ad6a`
