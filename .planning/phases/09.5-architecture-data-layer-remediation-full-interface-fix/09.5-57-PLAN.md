# Plan 09.5-57: Residual Interface Boundary Closure

Date: 2026-05-07
Status: In progress

## Goal

Remove remaining business logic, data providers, fallback stores, direct ORM handles, and direct SQL from interface layers so web, REST, tRPC, CLI, TUI, and future interfaces invoke the same application services/facades.

## Research Inputs

- `09.5-53-BOUNDARY-GAP-RESEARCH.md`
- `09.5-54-WEB-BOUNDARY-GAP-RESEARCH.md`
- `09.5-55-API-TRPC-ROUTER-BOUNDARY-GAP-RESEARCH.md`
- Latest upstream Symphony SPEC: `https://raw.githubusercontent.com/openai/symphony/refs/heads/main/SPEC.md`

## Task 1: Web Runtime Closure

Owned by web worker.

Targets:

- `apps/web/src/routes/docs/[id]/edit/+page.server.ts`
- `apps/web/src/lib/server/skills.ts`
- `apps/web/src/routes/api/skills/+server.ts`
- supporting `src/application/docs/**` and `src/application/skills/**`

Acceptance:

- Web route/helper files stop doing direct `EntityManager`, `getKysely`, SQL, or skill persistence.
- Web calls application services through request application scope/caller.
- Focused web tests pass.

## Task 2: REST Fallback Store Closure

Owned by REST worker.

Targets:

- `apps/server/src/api/routes/tasks.ts`
- `apps/server/src/api/routes/docs.ts`
- `apps/server/src/api/routes/memory.ts`
- `apps/server/src/api/routes/sprints.ts`
- `apps/server/src/api/routes/saved-views.ts`
- `apps/server/src/api/routes/notifications.ts`
- `apps/server/src/api/routes/search.ts`

Acceptance:

- Runtime routes do not own local `Map` stores, seeded fallback providers, or stub result business behavior.
- Missing dependencies return canonical application/HTTP errors rather than local fake data.
- Focused REST parity tests pass or are updated to assert application-source behavior.

## Task 3: Router Runtime Closure

Owned by router worker.

Targets:

- `apps/server/src/router/rules-engine.ts`
- `src/application/routing.ts`
- routing tests

Acceptance:

- Router evaluator does not initialize repositories or persist malformed-rule mutations.
- Malformed-rule disable/update behavior is owned by application routing service.
- Router runtime evaluates supplied rules/facts only.

## Task 4: tRPC Residual Closure

Local integration task after worker results.

Targets:

- `apps/server/src/runtime/trpc/routers/**`
- `apps/server/src/trpc/routers/**`
- `apps/server/src/trpc/context.ts`

Acceptance:

- Routers parse input and call application services/facades.
- Direct `ctx.em`, `requireTrpcEntityManager`, and router-local persistence selection are either eliminated from runtime routers or isolated behind a single composition adapter with explicit boundary allowance.
- Router tests continue to pass.
