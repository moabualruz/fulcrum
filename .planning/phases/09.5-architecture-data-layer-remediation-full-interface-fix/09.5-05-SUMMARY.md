## Implementation Notes

- `src/cli/import.ts`, `src/cli/export.ts`, `src/cli/sprints.ts`, `src/cli/artifact.ts`, `src/cli/connectors.ts`, `src/cli/notify.ts`, and `src/cli/settings.ts` now route through `createLocalCaller` or injected caller fixtures.
- `src/cli/product.ts` routes read/write product subcommands through caller fixtures while preserving `product init` database initialization for existing doctor and repo diagnostics.
- `src/tui/index.ts` no longer performs direct entity lookups for display enrichment; caller metadata is collected through `auth.whoami` and `flags.list`.

- `src/index.ts` registers `settings` at the root CLI entrypoint so `bun run src/index.ts settings --help` works, matching plan acceptance.
