# Phase 9.5 — Pattern Map

## Purpose

Concrete implementation analogs for Phase 9.5 plans. Read before executing any plan that creates `src/application/**`, rewires adapters, or removes ProductDb/product-kernel runtime paths.

## Application Boundary Patterns

| Target | Closest Existing Analog | Reuse Pattern |
|--------|--------------------------|---------------|
| `src/application/tasks/` | `src/services/TaskService.ts`, `src/server/trpc/routers/tasks.ts`, `src/db/repositories/tasks/TaskRepository.ts` | Move service first, expose command/query functions, keep repository-backed behavior. |
| `src/application/docs/` | `src/services/DocService.ts`, `src/db/entities/docs/*`, `src/server/trpc/routers/docs.ts` | Preserve document/version/link behavior; collab persistence must call application command. |
| `src/application/sprints/` | `src/services/SprintService.ts`, `src/server/trpc/routers/sprints.ts`, `src/cli/sprints.ts` | Replace CLI PGlite path with `createLocalCaller()` after router delegates to application. |
| `src/application/runs/` | `src/services/runs.ts`, `src/db/entities/orchestration/AgentRun.ts` | Fold function services into commands/queries; preserve Sandcastle/Symphony run metadata. |
| `src/application/artifacts/` | `src/services/artifacts.ts`, `src/db/entities/artifacts/Artifact.ts`, `src/db/entities/sandbox/Artifact.ts` | Normalize DTOs before adapter rewires; preserve checksum/retention behavior. |
| `src/application/dashboard/` | `src/web/src/lib/server/dashboard.ts`, `src/web/src/lib/product-queries.ts` | Convert raw SQL reads to MikroORM QueryBuilder or repository methods. |
| `src/application/notifications/` | `src/notifications/*`, `src/db/entities/notifications/*` | Route bell counts, fanout, delivery, quiet hours through app queries/commands. |
| `src/application/search/` | `src/db/entities/search/*`, existing search route/screen callers | Application query owns saved search + FTS read model; outbox feeds index writes. |
| `src/application/repos/` | `src/db/entities/repos/*`, `src/product-kernel/store/repo-files.ts` | Add missing entity/repository coverage for tree/blame/content; retire store runtime imports. |
| `src/application/audit/` | `src/web/src/lib/server/audit.ts`, `src/product-kernel/store/audit.ts` | Preserve audit export semantics, remove product-kernel EventRow dependency. |
| `src/application/connectors/` | `src/product-kernel/store/bitbucket.ts`, `gitlab.ts`, `github.ts`, `settings-connectors-credentials.ts` | Add connector entities/repositories, then repoint CLI/TUI/settings routes. |

## Adapter Patterns

| Adapter | Existing File | Required Shape |
|---------|---------------|----------------|
| tRPC | `src/server/trpc/routers/tasks.ts` | validate input, call `src/application/**`, map AppError to tRPC error, no `em.` access. |
| REST/Hono | `src/api/hono.ts`, `src/api/routes/*.ts` | single Hono app, `@hono/zod-openapi` route schemas, call application commands/queries, no product-kernel stores. |
| Web loaders/actions | `src/web/src/routes/**/+page.server.ts`, `+server.ts` | parse params/form data, call application query/command, return identical data shape. |
| CLI | `src/cli/local-caller.ts`, `src/cli/commands/**` | use `createLocalCaller()` for data workflows, preserve stdout/stderr/exit codes and `--json`. |
| TUI | `src/tui/index.ts`, `src/tui/screens/**` | use `buildCaller()` data queries; remove `enrichTuiCaller()` direct DB enrichment. |
| Workers | `src/orchestration/symphony/**`, `src/notifications/**` | state mutations through application commands; read-only EM allowed only behind application query or explicitly documented performance path. |

## Boundary Tests

Create the enforcement tests before implementation:

- `src/architecture/boundary.test.ts` rejects `openPglite|openProductDb|getProductDb|ProductDb|from .*product-kernel` under `src/web/src/routes`, `src/cli`, `src/tui`, `src/api`, `src/router`, `src/server/trpc`.
- `src/architecture/no-raw-sql.test.ts` rejects `.execute(` and `.query(` outside product-kernel legacy migrations and test fixtures.
- `src/architecture/migrations.test.ts` rejects product-kernel `runMigrations()` runtime callers and asserts MikroORM migrator path is used.
- `src/architecture/trpc-completeness.test.ts` requires routers for notifications, search, orchestration, repos, connectors, and webhooks.
- `src/architecture/security-regression.test.ts` covers Phase 3 CR-01..04 and WR-05.

## Data Flow

```
Web loader/action -> src/application/{domain}/{queries,commands}.ts -> MikroORM repository/entity -> database
tRPC procedure    -> src/application/{domain}/{queries,commands}.ts -> MikroORM repository/entity -> database
Hono route        -> src/application/{domain}/{queries,commands}.ts -> MikroORM repository/entity -> database
CLI command       -> createLocalCaller() -> tRPC -> application -> MikroORM -> database
TUI screen        -> buildCaller()       -> tRPC -> application -> MikroORM -> database
Worker            -> application command/query -> MikroORM -> outbox/EventBus/search/notifications
```

## Files That Must Not Break

- `src/cli/local-caller.ts` — CLI in-process tRPC path.
- `src/tui/index.ts` — `buildCaller()` path and screen registry.
- `src/db/db.module.ts` — needle-di repository/container bindings.
- `src/db/mikro-orm.config.ts` and `src/db/migrator-service.ts` — migration authority.
- `src/api/hono.ts` — sole REST/OpenAPI entry point after merge.
- `src/web/src/lib/components/app/nav-items.ts` — primary navigation contract.
- `src/subscriptions/event-bus.ts` — in-process transport, fed by outbox after migration.
