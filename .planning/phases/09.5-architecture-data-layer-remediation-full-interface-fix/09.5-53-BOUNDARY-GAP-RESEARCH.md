# 09.5-53 Boundary Gap Research

Source: subagent architecture audit, 2026-05-07.

## Findings

- Web server helpers still own persistence: `apps/web/src/lib/server/orm-helpers.ts`, `apps/web/src/lib/server/skills.ts`, `apps/web/src/lib/server/task-detail.ts`, `apps/web/src/lib/server/projects.ts`.
- Web doc edit route still reaches DB: `apps/web/src/routes/docs/[id]/edit/+page.server.ts`.
- Public API routes still keep fallback mutable stores: `apps/server/src/api/routes/tasks.ts`, `apps/server/src/api/routes/docs.ts`, `apps/server/src/api/routes/memory.ts`, `apps/server/src/api/routes/sprints.ts`, `apps/server/src/api/routes/saved-views.ts`.
- API/tRPC layers still resolve/pass ORM handles: `apps/server/src/api/routes/repos.ts`, `apps/server/src/api/routes/search.ts`, `apps/server/src/api/routes/kernel-tasks.ts`, `apps/server/src/runtime/trpc/routers/orgs.ts`, `apps/server/src/trpc/routers/artifacts.ts`.
- Router layer still owns default repository/rule initialization and mutation: `apps/server/src/router/rules-engine.ts`.
- UI imports DB entity types: `apps/web/src/lib/components/docs/FrontmatterForm.svelte`, `apps/web/src/lib/components/docs/FrontmatterYaml.svelte`, `apps/web/src/routes/docs/[id]/edit/+page.svelte`.

## Gate Gaps

- `scripts/check-module-boundaries.ts` does not reject interface-layer imports from `@mikro-orm`, `src/db/entities`, direct repository imports, `getKysely`, raw SQL, fallback `Map` stores, or `.svelte` DB entity imports.
- `src/architecture/boundary.test.ts` misses `@mikro-orm/postgresql`, `requireTrpcEntityManager`, `getKysely`, fallback `Map`, and `.svelte` imports.
- `src/architecture/no-raw-sql.test.ts` still allowlists some interface files instead of making them fail.
- `apps/web/src/routes/application-adapters.test.ts` samples selected routes only.

## Required Integration Map

- Event producers: project/task/doc/skill mutations, router rule changes, search indexing, job enqueue.
- Event consumers: audit/event views, search indexing tests, web settings pages, tRPC/API callers.
- Must not break: `apps/server/src/trpc/router.ts`, generated CLI tests, web route load/actions, application parity tests, Symphony conformance tests.
- Desired data flow: web/API/tRPC/CLI/TUI route or command -> application service/facade -> entity/repository/kernel adapter -> event/search/job side effects.
