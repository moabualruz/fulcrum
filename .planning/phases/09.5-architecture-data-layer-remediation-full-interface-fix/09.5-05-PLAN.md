<objective>
Move CLI and TUI data workflows onto `createLocalCaller()` / `buildCaller()` backed by application services while preserving command signatures, stdout/stderr, exit codes, `--json`, and screen behavior.
</objective>

<threat_model>
- T-05-01: CLI output changes break scripts. Mitigation: snapshot and JSON-shape regression tests for every migrated command.
- T-05-02: TUI screens render stale/fake data after direct enrichment removal. Mitigation: per-screen tests inject application-backed caller fixtures.
- Block on: high.
</threat_model>
