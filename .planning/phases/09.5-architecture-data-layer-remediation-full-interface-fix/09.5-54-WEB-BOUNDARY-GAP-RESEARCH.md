# 09.5 Web Boundary Gap Research

Source: Aquinas web-boundary subagent, 2026-05-07.

## Executive Finding

The web layer still has residual direct data access and business/data-provider logic. It should be an invocation and visualization layer over `src/application/**` services.

## Residual Files

- `src/web/src/routes/docs/[id]/edit/+page.server.ts`: direct `em.getKysely<any>()` document reads. Move edit-page retrieval into `src/application/docs` query facade and call through app scope.
- `src/web/src/lib/server/skills.ts`: SQL-backed skill API still lives in web server helper. Move commands/queries to `src/application/skills`.
- `src/web/src/routes/api/skills/+server.ts`: should import application skill commands, not `$lib/server/skills`.
- `src/web/src/lib/server/task-detail.ts`: move task detail projection, bulk update, and delete effects to application task modules.
- `src/web/src/lib/server/projects.ts`: replace with application project command/query re-export or delete after callers move; update/delete event dispatch belongs in application.
- `src/web/src/lib/server/sprints.ts`: replace with application sprint query/command calls; delete if redundant.
- `src/web/src/lib/server/settings.ts`: legacy `SqlExecutor` facade remains; split into application settings/custom-fields/connector modules.
- `src/web/src/routes/settings/connectors/+page.server.ts`: local `_configs: Map` and `_syncLog` test stores bypass application data source.
- `src/web/src/routes/settings/integrations/linear/+page.server.ts`: still references product DB/default org/runtime fallback path.
- `src/web/src/lib/server/orm-helpers.ts`: remove once route/helper callers move to application scope.

## Integration Map

- Web composition root allowed to keep database wiring: `src/web/src/lib/server/db.ts`.
- Request application scope: `src/web/src/lib/server/application-scope.ts`.
- Existing app facades to reuse first: `src/application/docs`, `src/application/tasks`, `src/application/projects`, `src/application/sprints`, `src/application/settings`, `src/application/skills`.
- Event dispatch should flow from application commands to domain events, not SvelteKit route handlers.
- Web route tests should inject application scope or app callers, never mock ORM/query builders directly.

## Guardrail Patterns

Ban in runtime web files, excluding tests and `src/web/src/lib/server/db.ts`:

- `@mikro-orm/postgresql`, `EntityManager`, `SqlExecutor`
- imports from `src/db/entities`, `src/db/repositories`, `product-kernel`
- `getKysely`, `ormSqlConnection`, `.query(`, `.execute(`
- `em.find`, `em.findOne`, `em.create`, `em.persist`, `em.flush`, `em.transactional`, `em.getRepository`
- `new Map`, `_configs`, `_syncLog`, `getProductDb`
