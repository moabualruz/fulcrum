## Yjs/Collab Audit Results (in-session)

**Finding:** No Yjs package dependency. Collab system is custom-built:
- `src/docs/collab/bun-ws-collab-server.ts` — Bun WS room manager (in-memory)
- `src/docs/collab/collab-provider-factory.ts` — Client config builder (YDoc stub)
- `src/docs/collab/collab-flag-guard.ts` — Feature flag guard
- `src/notifications/realtime-bell.ts` — Bell notification broadcaster
- `src/web/src/lib/collab/bell-websocket.ts` — Client WS with retry

**PGlite violations found:**
1. `src/subscriptions/pglite-bridge.ts` — imports PGlite directly, `emitNotify()` calls `pglite.query()`
2. `src/notifications/realtime-bell.ts` — `unreadCountForUser()` needs application query source

**Resolution:** Fix 2 violations, preserve feature-flagged architecture, don't restructure collab itself.
