<objective>
Close the cross-phase security gaps that Phase 9.5 absorbed: rate limiting, webhook secret encryption, and Phase 3 CR/WR findings.
</objective>

<threat_model>
- T-07-01: Public API accepts abusive request rates. Mitigation: Hono and tRPC rate-limit middleware with integration tests for 429.
- T-07-02: Webhook secrets persist in plaintext. Mitigation: application encryption/decryption wrapper and DB assertion that stored value differs from plaintext.
- T-07-03: Path traversal, XSS, non-deterministic IDs, approval race, or unsafe cleanup persist. Mitigation: named regression tests CR-01..04 and WR-05.
- Block on: high.
</threat_model>
